# 反作弊指挥中心 Web 面板 PRD

## 1. 产品概述
为 Minecraft 反作弊系统提供专业的 Web 管理面板，实现实时监控、玩家管理、案件审判、配置调整等功能，让管理员能够高效、安全地远程管理反作弊系统。
- 解决当前仅能通过游戏内命令管理的局限性，提供直观的可视化界面和远程管理能力
- 目标用户为服务器管理员和反作弊运营团队，提升管理效率和安全性

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 超级管理员 | 系统预设 | 全部功能、用户管理、系统配置 |
| 管理员 | 超级管理员创建 | 玩家管理、案件审判、配置调整、日志查看 |
| 观察者 | 管理员创建 | 仅查看仪表盘、玩家列表、日志（无操作权限） |

### 2.2 功能模块
1. **智能仪表盘**：风险地圈、关键指标卡片、实时威胁流、快捷操作磁贴
2. **玩家管理中心**：高级筛选、虚拟滚动表格、玩家详情抽屉、批量操作
3. **实时战场地图**：2D瓦片地图、玩家定位、轨迹回放、图层叠加
4. **案件审判中心**：看板视图、快速审判、键盘快捷键
5. **回放档案**：搜索列表、Three.js 3D播放器、分享链接
6. **配置中心**：检测模块管理、全局预设、惩罚模板、黑白名单
7. **AI实验室**：模型状态、异常集群、规则建议、模拟器
8. **审计日志**：高级查询、日志表格、导出、完整性校验
9. **跨服信誉联盟**：联盟仪表盘、贡献统计、隐私控制

## 3. 核心流程

### 3.1 管理员登录流程
管理员打开面板 → 输入用户名密码 → 系统验证 → 弹出TOTP输入框 → 输入6位验证码 → 系统颁发JWT令牌 → 进入智能仪表盘 → 首次登录弹出新手引导

```mermaid
flowchart TD
    "A[管理员打开面板]" --> "B[输入用户名密码]"
    "B" --> "C{系统验证}"
    "C" --> "|失败| D[显示错误，记录失败次数]"
    "D" --> "|5次失败| E[锁定IP15分钟]"
    "C" --> "|成功| F[弹出TOTP输入框]"
    "F" --> "G[输入6位验证码]"
    "G" --> "H{验证TOTP}"
    "H" --> "|失败| I[返回步骤G]"
    "H" --> "|成功| J[颁发JWT令牌]"
    "J" --> "K[进入智能仪表盘]"
    "K" --> "L{首次登录?}"
    "L" --> "|是| M[弹出新手引导]"
    "L" --> "|否| N[正常使用]"
```

### 3.2 案件审判流程
管理员进入审判中心 → 查看待处理案件 → 点击案件卡片 → 展开快速审判面板 → 查看证据摘要 → 按快捷键(A/S/D)或点击按钮 → 选择惩罚细节 → 确认判决 → 案件移至已结案列 → 记录审计日志

```mermaid
flowchart TD
    "A[进入审判中心]" --> "B[查看待处理案件]"
    "B" --> "C[点击案件卡片]"
    "C" --> "D[展开快速审判面板]"
    "D" --> "E[查看证据摘要]"
    "E" --> "F{选择判决}"
    "F" --> "|A键/释放| G[释放玩家，清除标记]"
    "F" --> "|S键/观察| H[加入观察名单，增强监控]"
    "F" --> "|D键/惩罚| I[弹出惩罚选项]"
    "I" --> "J[选择惩罚类型和时长]"
    "J" --> "K[确认判决]"
    "K" --> "L[案件移至已结案列]"
    "L" --> "M[记录审计日志]"
```

### 3.3 全局命令面板流程
管理员按Ctrl+K → 命令面板弹出 → 输入命令或自然语言 → 系统解析命令 → 执行对应操作 → 显示结果或跳转页面

    "K" --> "L[点击结果跳转]"

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深色背景（#0f0f23），搭配科技蓝（#00d4ff）作为强调色，警告橙（#ff6b35），危险红（#ff3366）
- **按钮风格**：圆角矩形（8px），悬停时发光效果，主要操作按钮带渐变背景
- **字体**：标题使用 JetBrains Mono（科技感），正文使用 Inter（清晰易读），数据使用等宽字体
- **布局风格**：左侧可折叠导航栏，顶部状态栏，中央内容区带卡片布局
- **图标风格**：Lucide图标库，线性风格，悬停时带微动画

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 认证模块 | 深色背景，居中登录卡片，发光边框，TOTP输入框带倒计时 |
| 智能仪表盘 | 风险地圈 | 环形图，安全区域绿色，警告区域橙色，高危区域红色，悬停显示数量 |
| 智能仪表盘 | 关键指标卡片 | 4列网格布局，每张卡片带迷你趋势线（折线图），数字大字体 |
| 智能仪表盘 | 实时威胁流 | 终端风格黑色背景，绿色/橙色/红色文字，自底向上滚动动画 |
| 玩家管理 | 玩家表格 | 紧凑型表格，风险分进度条（渐变色），悬停高亮行，多选复选框 |
| 玩家管理 | 详情抽屉 | 右侧滑出，半透明背景，雷达图（Chart.js），时间线（垂直滚动） |
| 实时地图 | 玩家圆点 | Leaflet地图，圆点颜色渐变（绿→橙→红），大小动态变化，方向箭头 |
| 案件审判 | 看板视图 | 三列布局，卡片可拖拽，列标题带计数，拖拽时卡片半透明 |
| 配置中心 | 模块卡片 | 网格布局，每张卡片带开关按钮、滑块、描述文字，修改时发光提示 |

### 4.3 响应式设计
- **桌面优先**：主要针对1920x1080及以上分辨率设计，支持1440px、2560px
- **移动端适配**：侧边栏自动隐藏，表格转为卡片列表，地图全屏显示
- **触摸优化**：按钮增大触摸区域，滑动操作替代部分点击，长按显示详情

### 4.4 动效设计
- **页面加载**：骨架屏加载动画，数据加载完成后渐入显示
- **数据更新**：WebSocket推送数据时，对应元素闪烁提示，平滑过渡更新
- **交互反馈**：按钮点击涟漪效果，拖拽元素阴影变化，悬停元素发光
- **全局命令面板**：从顶部滑入，背景模糊，关闭时滑出消失

## 5. 安全设计

### 5.1 认证安全
- JWT双令牌机制：access_token 15分钟有效，refresh_token 7天有效
- TOTP多因素认证：使用Speakeasy库生成和验证6位验证码
- 暴力破解防护：同一IP连续5次失败锁定15分钟

### 5.2 权限控制
- RBAC模型：超级管理员/管理员/观察者三级
- API端点权限校验：每个API请求验证用户角色权限
- 页面元素级权限：无权限按钮自动隐藏或禁用

### 5.3 数据安全
- HTTPS强制：TLS 1.3，HSTS头
- 输入验证：后端严格校验所有用户输入
- XSS防护：HTML实体编码输出
- CSRF防护：SameSite Cookie + Bearer Token
- 审计日志：所有操作记录不可变日志，支持哈希校验
