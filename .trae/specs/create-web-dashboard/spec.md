# 反作弊指挥中心 Web 面板 Spec

## Why
当前反作弊系统仅通过游戏内命令和配置文件进行管理，缺乏直观的可视化界面和远程管理能力。需要一个专业的 Web 面板来提供实时监控、玩家管理、案件审判、配置调整等功能，让管理员能够高效、安全地管理反作弊系统。

## What Changes
- 新增独立 Web 应用（前后端分离架构）
- 新增 RESTful API 服务与 WebSocket 实时通信
- 新增安全认证体系（JWT + MFA + RBAC）
- 新增九大功能模块：智能仪表盘、玩家管理、实时地图、案件审判、回放档案、配置中心、AI实验室、审计日志、跨服信誉
- 新增全局命令面板（Ctrl+K）与新手引导系统
- **BREAKING** 需要独立部署 Web 服务（Docker + Nginx）

## Impact
- Affected specs: 核心检测系统、玩家档案系统、决策中心
- Affected code: 需新增 Web 后端服务、前端 SPA 应用、API 接口层、数据库扩展

## ADDED Requirements

### Requirement: 安全架构
系统 SHALL 实现多层安全防护：
- 传输层：强制 HTTPS/WSS，TLS 1.3，HSTS
- 认证层：JWT 双令牌机制（access 15分钟 + refresh 7天），TOTP 多因素认证，暴力破解锁定（5次失败锁定15分钟）
- 授权层：RBAC 权限模型（超级管理员/管理员/观察者三级），API端点权限校验，页面元素级权限控制
- 输入验证：后端严格校验，参数化查询防SQL注入，HTML实体编码防XSS
- CSRF防护：SameSite Cookie + CSRF Token，API使用Bearer Token
- 审计日志：所有管理操作记录到不可变日志（操作人、时间、IP、变更详情），支持导出和哈希校验
- 加密存储：敏感配置AES-256加密，支持HSM可选
- 依赖安全：定期更新，SRI校验，CSP头限制脚本来源

#### Scenario: 用户登录认证
- **WHEN** 管理员输入正确的用户名密码并完成TOTP验证
- **THEN** 系统颁发access_token（15分钟有效）和refresh_token（7天有效），返回用户角色权限列表

#### Scenario: 暴力破解防护
- **WHEN** 同一IP连续5次登录失败
- **THEN** 系统锁定该IP15分钟，记录安全事件，发送警报通知

### Requirement: 性能优化
系统 SHALL 实现高性能架构：
- 前端：SPA + 路由懒加载，首屏加载<2秒，虚拟滚动支持万级列表
- WebSocket：仅推送变更数据，带宽<5KB/s，支持二进制帧压缩
- 缓存：Service Worker 应用壳缓存，IndexedDB 数据缓存，Redis 热点数据缓存
- 后端：API速率限制（100 req/min），过载熔断保护，数据库读写分离
- 响应时间：API平均响应<100ms，WebSocket延迟<50ms

#### Scenario: 大列表虚拟滚动
- **WHEN** 管理员查看包含10000+玩家的列表
- **THEN** 页面仅渲染可视区域约50条记录，滚动流畅无卡顿，内存占用<100MB

#### Scenario: 实时数据推送
- **WHEN** 系统检测到新的作弊告警
- **THEN** WebSocket推送告警事件（<5KB），前端实时更新仪表盘和通知中心，延迟<50ms

### Requirement: 全局命令面板
系统 SHALL 提供全局命令面板（Ctrl+K / ⌘K）：
- 支持自然语言输入和命令语法
- 支持快捷操作：封禁玩家、查看档案、地图定位、运行扫描
- 支持模糊搜索玩家、配置项、日志
- 新手友好，降低记忆负担

#### Scenario: 快捷封禁操作
- **WHEN** 管理员在命令面板输入 "ban Steve 7d 杀戮光环"
- **THEN** 系统解析命令，弹出确认对话框，确认后执行封禁并记录审计日志

#### Scenario: 快速定位玩家
- **WHEN** 管理员输入 "profile Alex"
- **THEN** 系统立即跳转到玩家Alex的详情页面

### Requirement: 智能仪表盘
系统 SHALL 提供智能仪表盘首页：
- 风险地圈：环形图显示实时风险分布（安全/警告/高危），支持点击下钻
- 关键指标卡片：在线玩家、嫌疑数、今日拦截、待审案件，含24小时迷你趋势线
- 实时威胁流：终端风格事件流，自底向上滚动，颜色区分严重度
- 快捷操作磁贴：全服扫描、维护模式、安全通告广播

#### Scenario: 风险下钻查看
- **WHEN** 管理员点击风险地圈的"高危"区域
- **THEN** 系统显示所有高危风险玩家的筛选列表

### Requirement: 玩家管理中心
系统 SHALL 提供高级玩家管理功能：
- 多维度筛选：风险分、客户端品牌、在线状态、违规历史、IP国家
- 虚拟滚动表格：紧凑型，支持多选批量操作
- 玩家详情抽屉：身份卡片、六维雷达图、违规时间线、关联账号网络图
- 玩家对比模式：并排显示两名玩家特征，识别共享账号
- 快捷操作：观察/幻象/审判/封禁，导出证据包

#### Scenario: 批量标记观察
- **WHEN** 管理员多选5名可疑玩家并点击"批量观察"
- **THEN** 系统将这5名玩家加入观察名单，启动增强监控，记录操作日志

#### Scenario: 查看关联账号
- **WHEN** 管理员打开玩家详情抽屉查看关联账号
- **THEN** 系统显示小号网络图，节点大小表示风险，连线粗细表示关联强度

### Requirement: 实时战场地图
系统 SHALL 提供2D实时地图：
- 瓦片地图：基于服务器世界生成静态瓦片
- 玩家圆点：颜色=风险等级，大小=移动速度，方向箭头
- 交互：点击弹出迷你档案卡，框选批量选择
- 轨迹回放：显示过去60秒移动轨迹，异常段红色虚线
- 图层叠加：蜜罐位置、作弊热点热力图、审判空间

#### Scenario: 框选批量操作
- **WHEN** 管理员在地图上框选一组玩家
- **THEN** 系统显示批量操作菜单（观察/审判/幻象），执行后更新所有选中玩家状态

### Requirement: 案件审判中心
系统 SHALL 提供案件审判功能：
- 看板视图：待处理/审理中/已结案三列拖拽
- 快速审判：点击卡片展开判决面板，证据摘要+三按钮（释放/观察/惩罚）
- 键盘快捷键：A=释放，S=观察，D=惩罚
- 高级审判：链接完整档案页，查看回放和原始日志

#### Scenario: 快速审判流程
- **WHEN** 管理员点击案件卡片按下"D"键
- **THEN** 系统弹出惩罚选项面板，选择后执行判决，案件移至已结案列

### Requirement: 回放档案
系统 SHALL 提供回放档案管理：
- 搜索列表：按时间、玩家、规则搜索，缩略图预览
- 内嵌播放器：Three.js 3D回放，速度控制，视角切换（自由/第一/第三）
- 分享导出：生成7天有效加密分享链接

#### Scenario: 回放查看
- **WHEN** 管理员点击回放记录
- **THEN** 系统打开内嵌播放器，显示3D场景，可控制播放速度和视角

### Requirement: 配置中心
系统 SHALL 提供可视化配置管理：
- 检测模块管理：卡片式，开关+灵敏度滑块（1-10），热重载即时生效
- 全局预设：竞技/生存/宽松模式一键切换，自定义预设保存
- 惩罚模板：可视化编辑阶梯，关联时长和通知模板
- 黑白名单：批量导入/导出玩家、IP、客户端品牌

#### Scenario: 灵敏度调整
- **WHEN** 管理员拖动"杀戮光环检测"灵敏度滑块从5到8
- **THEN** 系统实时更新检测模块配置，无需重启服务，记录配置变更日志

### Requirement: AI实验室
系统 SHALL 提供AI模型管理界面：
- 模型状态：版本、AUC、训练样本数、上次训练时间
- 异常集群：可疑行为集群展示，一键转为临时规则
- 规则建议：自动生成检测规则提案，显示预测准确率
- 模拟器：输入特征值观察模型输出分数

#### Scenario: 采纳规则建议
- **WHEN** 管理员查看AI规则建议并点击"采纳"
- **THEN** 系统将建议规则添加到检测模块，标记为临时规则，开始生效

### Requirement: 审计日志
系统 SHALL 提供完整审计日志功能：
- 高级查询：时间、操作者、类型、目标、IP组合条件
- 虚拟滚动表格：展开查看JSON载荷详情
- 导出：CSV/JSON格式，支持定期归档
- 完整性验证：哈希链校验工具

#### Scenario: 日志完整性校验
- **WHEN** 管理员点击"验证日志完整性"
- **THEN** 系统计算哈希链，显示校验结果（通过/失败），失败时标记可疑条目

### Requirement: 跨服信誉联盟
系统 SHALL 提供可选的跨服信誉联盟功能：
- 联盟仪表盘：成员服务器数、共享威胁情报数
- 贡献消耗：上传/下载特征指纹统计
- 隐私控制：匿名化设置，仅共享行为特征哈希和标签

#### Scenario: 查看联盟贡献
- **WHEN** 管理员打开信誉联盟页面
- **THEN** 系统显示本服贡献排名、下载的威胁情报数、隐私设置状态

### Requirement: 新手引导
系统 SHALL 提供交互式新手引导：
- 首次登录自动弹出向导
- 引导内容：仪表盘解读、查看玩家详情、处理告警、调整敏感度
- 可跳过，可从帮助菜单重新启动

#### Scenario: 首次登录引导
- **WHEN** 新管理员首次登录
- **THEN** 系统弹出交互式向导，逐步引导了解核心功能，完成后标记已引导

## MODIFIED Requirements
无修改需求，此为全新功能模块。

## REMOVED Requirements
